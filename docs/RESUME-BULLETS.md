# Monelytics — personal finance app

- Built a responsive personal finance dashboard with **Angular, TypeScript, JavaScript, HTML, and CSS**, helping users understand spending, manage budgets, and track savings goals in one accessible interface.
- Developed secure financial APIs with **Java and Spring Boot** and tested **Amazon Web Services (AWS)** infrastructure configuration, protecting account access and making the application ready for a controlled future deployment.
- Designed reliable financial storage with **PostgreSQL**, configured **Copilot** review guidance, and packaged the application with **Docker**, making setup repeatable and keeping transactions, budgets, and savings records consistent.

These bullets describe implemented work without claiming production customers, compliance certification, measured business outcomes or live AWS hosting. Copilot repository instructions were configured; Copilot was not used to generate the implementation.
